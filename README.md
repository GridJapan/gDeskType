# gDeskType

Claude などの AI エージェントから呼び出して、macOS のデスクトップにある任意のウィンドウの指定位置へキーボード入力するツールです。

- **状態: 設計段階**（実装はまだありません）
- **対応 OS: macOS のみ**

マウスを動かさず、ウィンドウを前面に出さずに入力することを基本動作にします。

## 構成

| 層 | 中身 |
|---|---|
| 本体 | Swift 製の単一バイナリ `gdesktype`。Accessibility (AX) API と CGEvent を直接呼ぶ |
| 呼び出し口 1 | MCP サーバ（stdio）。Claude Code のユーザースコープに登録し、どのプロジェクトからでも呼べるようにする |
| 呼び出し口 2 | CLI（例: `gdesktype type --app Notes --at 120,340 "こんにちは"`） |
| 設定 | `~/.config/gdesktype/anchors.json`。名前を付けた入力位置（アンカー）を保存する |

## MCP ツール

| ツール | 役割 |
|---|---|
| `list_windows` | ウィンドウ一覧（pid・ウィンドウID・アプリ名・タイトル・位置・大きさ） |
| `snapshot_window` | 指定ウィンドウだけを撮影する（前面化不要）。座標決めに使う |
| `inspect_at` | 座標にある UI 要素の role・識別子・編集可否・パスワード欄かどうかを返す |
| `type_at` | 指定位置に文字列を入力する |
| `key_at` | Return・Tab・Command + A などのキーを送る |
| `save_anchor` / `list_anchors` | 位置に名前を付けて保存・一覧する |

## 位置の指定方法（優先順）

| 順 | 指定方法 | 特徴 |
|---|---|---|
| 1 | AX の識別子・要素パス | ウィンドウの移動やリサイズでずれない |
| 2 | ウィンドウ内の相対座標 | ウィンドウ左上が原点 |
| 3 | 画面の絶対座標 | 最後の手段 |

`inspect_at` で取れた識別子はアンカーに一緒に保存し、次回は識別子で探す。見つからない場合だけ座標を使う。

## 入力方式（上から順に試す）

| 段 | 方式 | 前面化 | マウス | 向いている対象 |
|---|---|---|---|---|
| A | AX で値を直接書き込む（`kAXValueAttribute`） | しない | 使わない | 標準 Cocoa の入力欄。値の置き換えのみ |
| B | AX で要素にフォーカスを当て、`CGEventPostToPid` で文字を送る | しない | 使わない | 多くのアプリ。追記やキー操作も可 |
| C | 前面に出してクリックし、文字を送る | する | 使う | A・B が効かないアプリ。`allow_foreground: true` を明示した時だけ |

- 入力後に AX で値を読み直し、入力できたかを返す（`landed: true/false`）
- 背景のアプリが B を受け付けるかはアプリ次第で、**未検証**。Chrome・Electron 製・Avalonia 製などは実装時に検証表を作る（Avalonia は AX に値を公開しないため A は効かない見込み）

## 安全策

- **パスワード欄には入力しない**。`AXSecureTextField` のほか、Qt のように subrole を設定しないツールキットに備え、識別子に `Password` を含む要素も拒否する
- 入力した文字列はログに残さない（文字数と宛先のみ）
- 送信・購入・削除など取り消せない操作につながるキー送出は、ツール側で区別できないため、呼び出し側（エージェント）の運用で事前確認する

## 必要な権限

| 権限 | 付与先・用途 |
|---|---|
| アクセシビリティ | エージェントを動かしているアプリ（ターミナルや Claude デスクトップアプリ）に付与する。未付与だと AX 呼び出しが `-25211` で失敗する |
| 画面収録 | `snapshot_window` を使う場合のみ必要 |

## 実装の順番

1. `list_windows`・`inspect_at`・`type_at`（方式 A・B）
2. 代表的なアプリで A・B のどちらが効くかの検証表
3. `snapshot_window` とアンカー保存
4. 方式 C と、パスワード欄拒否のテスト
